# AgentBell v2.22.0 执行计划与交付检验

日期：2026-11-11
范围：三项可叠加功能 + DeepSeek Harness 技能/插件接入
交付标准：两项大任务均可直接使用，测试、构建与隔离冒烟全部通过

## 1. 目标与边界

### 1.1 三项功能

| 功能 | 目标 | 不做什么 |
| --- | --- | --- |
| 本地语音播报 | 通知弹窗时用系统 TTS 播报标题、状态、耗时与可选摘要 | 不调用云端 TTS，不上传文本，不替代提示音 |
| MCP Server | 在现有本机 HTTP 服务上暴露 MCP 工具，任何 MCP 客户端可直接发通知与查历史 | 不新增监听端口，不暴露审批、自动继续或命令执行 |
| Token / 成本守卫 | 统计 Claude Code / Qoder / Codex 的 token；按日预算触发提醒；统计页展示 | 不做计费对账，不读取对话正文，不上传用量 |

### 1.2 DeepSeek Harness 接入

- **Skill**：`agentbell-notify`，用 `SKILL.md` + 仅标准库脚本调用本机 `/notify`，可被 dsh、Claude Code、Codex 共用。
- **Bundle 插件**：官方 bundle 格式（`dsh.bundle.patch` + `cordis.patch.yml`），监听 `session/event` 的 `turn/end` 自动通知。
- **安全边界**：token 运行时读取；只连 `127.0.0.1`；不执行 shell；不提供批准、继续或提示词注入能力。

### 1.3 明确非目标

- 不做手机远程审批、云同步、Web 控制台、Agent 编排。
- 本轮不推送标签、不发布 GitHub Release、不切换生产进程；这些步骤需单独授权。
- 不改动 `develop-cc` 供应商感知相关代码。

## 2. 架构设计

### 2.1 语音播报

新增 `agentbell/voice.py`：

- `format_voice_text(notification, config)`：按 `voice.template` 渲染，截断到 `max_chars`。
- `build_command(text, config, platform, which)`：Windows PowerShell / macOS `say` / Linux `spd-say` 或 `espeak-ng`。
- 文本写入临时 UTF-8 文件，命令只接收文件路径，避免任何 shell 注入。
- `VoicePlayer` 在后台异步播放；新通知到达时停止上一条，避免叠音；播放结束清理临时文件。

配置新增：

```json
"voice": {
  "enabled": false,
  "min_priority": "normal",
  "rate": 0,
  "include_summary": true,
  "max_chars": 120,
  "template": "{title}，{status_label}"
}
```

接线：`AgentBellApp._show` 播放声音后调用语音；`silent` 通知、低于最低优先级、免打扰已抑制的通知不播报；设置页「模板与声音」新增开关、语速、摘要开关与试听。

### 2.2 MCP Server

新增 `agentbell/mcp.py`，在 `api.py` 增加 `POST /mcp`：

- JSON-RPC 2.0：`initialize`、`notifications/initialized`、`tools/list`、`tools/call`、`ping`。
- 工具：
  - `notify`：标题、状态、摘要、耗时、来源、去重、会话、运行、优先级、静音等；复用现有通知校验与规则引擎。
  - `search_history`：按关键字、状态、来源、会话、运行过滤，最多 50 条。
  - `get_status`：版本、鉴权状态、历史条数、端口。
- 鉴权：`/mcp` 与 `/notify` 一样要求 token；同时接受 `X-Token` 与 `Authorization: Bearer`。
- 传输：Streamable HTTP 的 JSON 响应模式，无状态；不引入额外依赖。

### 2.3 Token / 成本守卫

新增 `agentbell/usage.py`：

- Claude / Qoder JSONL：读取 `assistant.message.usage`，按 `message.id` 去重，累计输入、输出、缓存读、缓存写。
- Codex JSONL：读取 `event_msg.payload.type == token_count` 的 `last_token_usage`，累计增量，避免累计值重复。
- 价格表可配置 `usage.pricing`，默认只统计 token；配置价格后按模型子串匹配估算 USD。
- 文件级缓存按 `(mtime, size)` 失效；后台线程扫描，不阻塞 UI。
- 日预算：`usage.daily_token_budget`、`usage.daily_cost_budget`、`usage.alert_percent`。
- 每个自然日每个阈值只提醒一次，`dedupe_key = usage:<date>:<kind>:<percent>`。

配置新增：

```json
"usage": {
  "enabled": true,
  "scan_interval_seconds": 300,
  "daily_token_budget": 0,
  "daily_cost_budget": 0,
  "alert_percent": 80,
  "pricing": {}
}
```

接线：新增 `UsageScanner`；统计页增加「Agent 用量」卡片；设置页「Agent 会话」增加预算控件；通知进入现有规则、免打扰与渠道链路。

### 2.4 DeepSeek Harness

目录：

```text
integrations/deepseek-harness/
  README.md
  agentbell-notify/
    SKILL.md
    agentbell_notify.py
  dsh-plugin/
    package.json
    cordis.patch.yml
    lib/index.js
    README.md
```

- 技能脚本：参数 `--title/--status/--summary/--duration/--session-id/--source/--config/--url`；配置发现顺序为显式参数、`AGENTBELL_CONFIG`、常见用户目录；输出仅结果，不打印 token。
- Bundle：`package.json` 声明 `dsh.bundle.patch`；patch 插入插件行；插件导出 `name/inject/apply`，订阅 `session/event`，`turn/end` 时 POST。
- 状态映射：`turn/end reason.kind=error` → `failed`；`aborted` → `canceled`；其余 → `succeeded`。
- 附带 `origin.pid=process.pid` 与 `working_dir=session.header.cwd`。

## 4. 审查门禁

### 4.1 设计审查

- [x] 语音只使用系统本地 TTS，文本通过临时文件传递，无 shell 拼接。
- [x] MCP 不新增监听面、不新增无鉴权路由，工具参数有长度与枚举校验。
- [x] 用量扫描只读会话文件，不解析正文，不记录敏感文本。
- [x] dsh 插件无 default export，导出 `name/inject/apply`，bundle patch 可被官方加载器解析。

### 4.2 代码审查

- [x] 配置字段有默认值、范围校验与 `config.example.json` 示例。
- [x] 设置保存后语音、用量扫描器立即应用新配置，无需重启。
- [x] 扫描线程可停止、可唤醒，退出时 join。
- [x] 所有新增外部调用有超时、异常兜底与日志，不打印 token。
- [x] 无 `shell=True`、无命令拼接、无外部任意 URL。

### 4.3 安全审查

- [x] `/mcp` 缺失或错误 token 返回 401。
- [x] MCP `notify` 不接受 `focus` 动作伪造，不接受本地路径（除非显式允许）。
- [x] 语音文本来自通知字段，经过 TTS 文件传递，无注入面。
- [x] dsh 插件仅 POST 本机地址，token 不在源码或日志中出现。
- [x] 预算提醒可被免打扰、静音与规则抑制，不绕过现有策略。

## 6. 风险与回滚

| 风险 | 处理 |
| --- | --- |
| 无 TTS 引擎 | 记录日志并静默降级，不影响通知 |
| Codex 用量格式变化 | 解析失败仅跳过该文件，不影响其他来源 |
| MCP 客户端协议差异 | 支持标准 JSON-RPC 与无状态 HTTP；文档给出 Claude Code / dsh 配置 |
| dsh 版本差异 | 插件声明 `engines.dsh` 范围，README 注明已验证版本 |
| 扫描大文件卡顿 | 后台线程 + 按 (mtime,size) 缓存 + 只对含 `usage` 的行做 JSON 解析 |

回滚：新增功能默认关闭或预算为 0；删除新增模块与配置字段即可恢复 2.21.0 行为，不改动历史数据库结构。
