## AgentBell 2.19.0

本次发布补全会话观测、搜索与归档能力，并把 macOS 与 Wayland 的桌面体验补齐到与 Windows 接近的水平，同时接入 Windows 与 macOS 的发布签名流水线。

### 会话与等待推断

- Agent 会话页新增 Codex、Gemini、Grok 三种会话文件来源，以及 OpenCode 的只读 SQLite 数据库来源；仍按项目分组，只读解析，不写入会话文件。
- 等待推断从 Claude Code / Qoder 扩展到 Codex、Gemini 与 Grok，沿用连续两次扫描加空闲阈值的判定，推断卡片继续带「推断」标记。

### 搜索、统计与归档

- 通知搜索支持 `status:` / `source:` / `priority:` / `session:` / `run:` / `ack:` 字段过滤，可与关键词、状态和来源筛选叠加，并支持中文别名与多值 OR。
- 数据统计提供 7 / 30 / 90 天区间，新增 CSV 导出，包含时间、状态、来源、标题、耗时与运行标识等列。
- 通知中心支持批量归档，归档范围可选进行中 / 已归档 / 全部，列表可按日期或来源分组。
- 托盘菜单新增快捷勿扰：30 分钟、1 小时或到明早。
- 规则区新增「试运行」：用一条样例通知查看命中的规则与最终字段，不写入历史。

### macOS 与 Wayland

- macOS 补齐全局快捷键、回到终端、空闲 / 全屏 / 会议 / 锁屏推断、终端启动与便携 Node 安装；回到终端需要辅助功能权限。
- macOS 自动更新改为使用 Release 中的 zip 包原地替换：下载并校验后退出程序，备份旧 `.app`，替换并重启；dmg 仅用于首次安装或手动覆盖。
- Wayland 通过 XDG Desktop Portal 的 GlobalShortcuts 接口注册全局快捷键；系统不允许应用主动切换窗口焦点，相关入口会给出说明。

### 签名与公证

- Windows CI 在配置 `WINDOWS_CERT_PFX_BASE64` 后使用 `signtool` 做 SHA-256 + RFC 3161 时间戳的 Authenticode 签名，并用 `/pa /all` 验证；未配置证书时跳过签名并给出警告。
- macOS CI 在配置 Developer ID 证书与 App Store Connect API Key 后启用 Hardened Runtime、Developer ID 签名、`notarytool` 公证与 `stapler` 装订；未配置证书时回退为 ad-hoc 签名，证书不完整时跳过公证并给出警告。
- 本地可用 `scripts/sign_windows.py` 与 `scripts/build_macos_packages.py` 复现同一套签名流程；密码与密钥只从环境变量或文件读取，不写入命令行输出。

### 平台与下载

- Windows x64：`AgentBell.exe`；Windows ARM64：`AgentBell-arm64.exe`。
- macOS Intel：`AgentBell-macos-x64.dmg` / `.zip`；Apple Silicon：`AgentBell-macos-arm64.dmg` / `.zip`。
- Linux x64 / arm64：`AgentBell-linux-<arch>.tar.gz`、`.AppImage`、`.deb`、`.rpm`。
- 全部资产由 `SHA256SUMS.txt` 校验；Windows、macOS 与 Linux 便携版都支持包内自动更新。

HTTP 服务仍只监听 `127.0.0.1`，会话记录只读，通知动作不执行外部命令，也不提供批准权限或自动继续。
