## AgentBell 2.18.0

本次发布把安装包扩展到 Windows ARM64 与 macOS（Intel / Apple Silicon）。Windows x64 与 Linux 四种格式保持兼容，原有配置与通知接口不变。

### Windows ARM64

- 新增原生 `windows-11-arm` 构建，使用 Arm64 Python、PySide6 与 PyInstaller，不再依赖 x64 模拟运行。
- Release 提供稳定命名 `AgentBell-arm64.exe` 与版本化副本 `AgentBell-<构建号>-arm64.exe`；x64 仍为 `AgentBell.exe` 与 `AgentBell-<构建号>.exe`。
- 更新器按当前架构选择资产：ARM64 系统优先 `AgentBell-arm64.exe`，x64 系统不会误选 ARM64 文件；Release 缺少对应架构时只打开 Release 页面。
- Windows 功能与 x64 版本一致：托盘、全局快捷键、全屏提醒、回到终端、提示音、包内自动更新。

### macOS（x64 / Apple Silicon）

- 新增 `AgentBell.app`，分别由 `macos-15-intel` 与 `macos-15` 原生构建，提供 `AgentBell-macos-x64.dmg`、`AgentBell-macos-arm64.dmg` 与同名 `.zip`。
- 配置、日志、数据库、`chat/` 与 Hook 状态统一存放在 `~/Library/Application Support/AgentBell/`，不写入只读的应用包。
- 开机自启使用 `~/Library/LaunchAgents/com.agentbell.app.plist`。
- 应用为 ad-hoc 签名（没有 Apple Developer ID 公证）。首次打开若被 Gatekeeper 拦截，请在 Finder 中右键应用选择「打开」，或到「系统设置 → 隐私与安全性」点「仍要打开」。
- macOS 最低版本为 14.0，与当前 PySide6 / Qt 的 universal2 构建一致。
- macOS 更新为手动方式：应用内会提示新版本并提供「打开 Release 页面」，不会下载或替换自身；请下载新的 `.dmg` 或 `.zip` 覆盖「应用程序」中的旧版。

### macOS 功能范围

- 可用：托盘、通知弹窗与全屏卡片（含多显示器）、通知中心、会话阅读、Agent 会话扫描、Hook 接入（Claude Code / Gemini CLI / Grok）、开机自启、提示音（`afplay`）。
- 暂不可用：全局快捷键、回到终端 / 窗口聚焦、空闲与全屏 / 会议 / 锁屏推断、便携 Node 与 Agent CLI 安装、应用内自动更新。相关入口会返回提示，不影响提醒主线；Agent 可继续使用系统已安装的 Node 与 CLI。

### 打包与流水线

- CI 测试矩阵扩展为 Windows x64/arm64、Linux x64/arm64、macOS x64/arm64。
- macOS 构建先用 PySide6 把 `assets/agentbell.svg` 渲染为 `.icns`，再由 PyInstaller `BUNDLE` 生成 `.app`，最后用 `ditto` 打 zip、`hdiutil` 打 dmg，并重新 ad-hoc 签名。
- 每个平台与架构各生成一份校验文件，发布任务合并为 `SHA256SUMS.txt`。
- 修复 Linux 提示音：没有 `winsound` 时改用 `paplay` / `aplay`；macOS 使用 `afplay`。

### 下载与校验

- Windows x64：`AgentBell.exe`；Windows ARM64：`AgentBell-arm64.exe`。
- macOS Intel：`AgentBell-macos-x64.dmg` / `.zip`；Apple Silicon：`AgentBell-macos-arm64.dmg` / `.zip`。
- Linux x64 / arm64：`AgentBell-linux-<arch>.tar.gz`、`.AppImage`、`.deb`、`.rpm`。
- 全部资产可用 `SHA256SUMS.txt` 校验。
