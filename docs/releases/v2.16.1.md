## AgentBell 2.16.1

本次发布新增 Linux x64 / arm64 通用版；Windows 版功能与配置保持兼容。v2.16.0 标签因 Linux CI 测试未通过而未发布，2.16.1 修复了跨平台路径解析与测试假设，功能与 2.16.0 相同。

### Linux 桌面支持

- 提供 `AgentBell-linux-x64.tar.gz` 与 `AgentBell-linux-arm64.tar.gz`，解压后直接运行 `AgentBell`，无需安装 Python 或 Qt。
- X11 会话完整支持窗口聚焦与「回到终端」、全屏 / 会议 / 锁屏检测、全局快捷键、系统托盘与 Agent 终端启动。
- Wayland 会话仍可弹窗、使用通知中心与托盘，但全局快捷键、窗口聚焦、全屏 / 空闲检测自动降级，并在界面与日志中提示。
- API Key 在 Linux 优先写入 Secret Service（`secret-tool`），没有可用密钥环时退化为 `plain:` base64，并在文档中标注仅编码、不加密。

### 更新与接入

- Linux 更新器按当前架构选择 `AgentBell-linux-<arch>.tar.gz`，只提取包内的 `AgentBell`；替换脚本使用 `/bin/sh`，等待进程退出、备份、替换失败回滚并原参数重启。
- 一键接入在 Linux 上改用 `AgentBell --hook --agent <id>` 子命令，配置写入、预览、备份、幂等与撤销规则与 Windows 一致。
- 便携 Node 与 Agent CLI 支持 Linux `tar.xz` 与 `runtime/node/bin`、`runtime/agents/bin` 路径布局。

### 跨平台修复

- 会话项目名改为同时识别 `/` 与 `\` 分隔符，Linux 上解析 Windows 风格工作目录时不再返回整段路径。
- 非 Windows 平台显式置空 Win32 API 句柄，窗口聚焦测试可在 Linux 正常运行。
- Linux 测试按平台校验 Hook 命令、PATH 分隔符、更新脚本与标题省略提示；Windows 桌面路径和 PowerShell 替换测试仅在 Windows 运行。

### 发布流水线

- GitHub Actions 新增 Linux x64 / arm64 测试与打包矩阵；标签发布同时上传 Windows exe、两个 Linux tar.gz 和合并后的 `SHA256SUMS.txt`。
- Windows 构建自动选用编号最大的 `AgentBell<数字>.spec`，本次使用 `AgentBell29.spec`。
- 合并校验文件时读取全部平台的 `SHA256SUMS*.txt`，去重排序后写入单个 `SHA256SUMS.txt`。

### 下载与校验

- Windows：`AgentBell.exe`（自动更新资产）或 `AgentBell-29.exe`，两者内容一致。
- Linux x64：`AgentBell-linux-x64.tar.gz`；Linux arm64：`AgentBell-linux-arm64.tar.gz`。
- 全部资产可用 `SHA256SUMS.txt` 校验。
