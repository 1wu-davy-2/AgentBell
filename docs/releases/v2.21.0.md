## AgentBell 2.21.0

本次更新集中打磨日常使用细节：托盘直接显示未读数字，弹窗卡片可点击进入通知中心，通知中心支持 Ctrl+F 聚焦搜索，历史数据库新增按天保留。

### 新增

- 托盘未读角标：有新通知时，托盘图标右下角显示未读数字，超过 99 显示 `99+`；打开通知中心清空未读后恢复普通图标。未读闪烁期间仍优先显示提醒图标，闪烁结束后回到角标状态。
- 弹窗直达通知中心：点击弹窗卡片的标题、摘要或空白区域，会关闭该弹窗并打开通知中心；「查看」「知道了」「稍后」「卡片动作」按钮的行为保持不变。
- Ctrl+F 快速搜索：在通知中心任意页面按 `Ctrl+F`，会切回通知记录页并聚焦搜索框；已有内容会全选，便于直接覆盖输入。
- 历史按天保留：新增 `history.retention_days`，与条数上限同时生效，`0` 表示只按条数清理。设置页「历史数据库」可直接调整条数上限与保留天数，保存后立即清理内存与数据库中的过期记录，并清理不再被引用的运行时间线。

### 说明

- 托盘未读角标随未读数量实时更新；右键菜单、勿扰模式，以及左键打开通知中心的行为保持不变。
- 清理历史只影响本地 SQLite 记录，不修改 Agent 会话文件，也不会执行任何外部命令。

### 平台与下载

- Windows x64：`AgentBell.exe`；Windows ARM64：`AgentBell-arm64.exe`。
- macOS Intel：`AgentBell-macos-x64.dmg` / `.zip`；Apple Silicon：`AgentBell-macos-arm64.dmg` / `.zip`。
- Linux x64 / arm64：`AgentBell-linux-<arch>.tar.gz`、`.AppImage`、`.deb`、`.rpm`。
- 全部资产由 `SHA256SUMS.txt` 校验；Windows、macOS 与 Linux 便携版都支持包内自动更新。

HTTP 服务仍只监听 `127.0.0.1`，会话记录只读，通知动作不执行外部命令，也不提供批准权限或自动继续。
