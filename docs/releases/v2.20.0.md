## AgentBell 2.20.0

本次新增托盘图标点击打开通知中心，托盘交互更顺手。

### 托盘

- 左键单击或双击托盘图标会打开通知中心；从 Windows 托盘溢出面板里点击同样生效。
- 右键仍显示原有菜单：打开通知中心、最近通知、勿扰模式、检查更新、关于与退出。
- 连续双击时通知中心只会被重复置前，不会重复创建窗口或写入历史。

### 平台与下载

- Windows x64：`AgentBell.exe`；Windows ARM64：`AgentBell-arm64.exe`。
- macOS Intel：`AgentBell-macos-x64.dmg` / `.zip`；Apple Silicon：`AgentBell-macos-arm64.dmg` / `.zip`。
- Linux x64 / arm64：`AgentBell-linux-<arch>.tar.gz`、`.AppImage`、`.deb`、`.rpm`。
- 全部资产由 `SHA256SUMS.txt` 校验；Windows、macOS 与 Linux 便携版都支持包内自动更新。

HTTP 服务仍只监听 `127.0.0.1`，会话记录只读，通知动作不执行外部命令，也不提供批准权限或自动继续。
