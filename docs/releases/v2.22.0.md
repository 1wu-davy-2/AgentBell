## AgentBell 2.22.0

本次更新加入三项常用能力：本地语音播报、MCP Server 工具接入，以及 Claude / Qoder / Codex 的 Token 与成本守卫；同时提供 DeepSeek Harness 的技能与 bundle 插件。

### 新增

- 本地语音播报：通知到达时可朗读「标题 + 状态」，可选摘要、语速与最低优先级；只调用系统自带 TTS（Windows System.Speech、macOS `say`、Linux `spd-say` / `espeak`），文本经临时 UTF-8 文件传递，不联网、不拼接 shell。静音、低优先级与没有等待输入的「进行中」通知默认不朗读。
- MCP Server：在现有本机 API 上新增 `POST /mcp`，实现 JSON-RPC 2.0 的 `initialize`、`tools/list` 与 `tools/call`。提供 `notify`、`search_history`、`get_status` 三个工具，复用原有通知管线、去重、规则与历史；支持 `X-Token` 与 `Authorization: Bearer`，缺失或错误 token 返回 401。
- Token / 成本守卫：后台只读增量扫描 Claude Code、Qoder 与 Codex 的会话记录，按今日汇总输入、输出与缓存 Token；可配置每日 Token 预算、每日成本预算、预警百分比与每百万 Token 单价。达到阈值时推送一条去重提醒，统计页新增「今日 Token 与成本」卡片。
- DeepSeek Harness 接入：`integrations/deepseek-harness/` 同时提供 `agentbell-notify` 技能（SKILL.md + 标准库 CLI）与官方 bundle 格式的 dsh 插件；插件在每轮 `turn/end` 自动上报，`error` 映射失败、`aborted` 映射取消。

### 配置

```json
"voice": {
  "enabled": false,
  "min_priority": "normal",
  "rate": 0,
  "include_summary": true,
  "max_chars": 120,
  "template": "{title}，{status_label}"
},
"usage": {
  "enabled": true,
  "scan_interval_seconds": 300,
  "daily_token_budget": 0,
  "daily_cost_budget": 0,
  "alert_percent": 80,
  "pricing": {}
}
```

`daily_token_budget` 与 `daily_cost_budget` 为 `0` 表示不限制；`pricing` 按模型名前缀匹配，键为 `input`、`output`、`cache_read`、`cache_write`，单位为每百万 Token。设置页「通知」可调语音，「Agent 会话」可调用量扫描与预算，保存后立即生效。

### 说明

- 语音与用量扫描都只在本机运行；用量扫描只读取 Token 计数字段，不解析或记录会话正文。
- MCP 不新增监听地址，仍只绑定 `127.0.0.1`；`notify` 不支持批准权限、自动继续或执行命令。
- DeepSeek Harness 插件要求 dsh `>= 0.2.2-rc.1 < 0.3.0`，安装与 token 查找顺序见 `integrations/deepseek-harness/README.md`。

### 平台与下载

- Windows x64：`AgentBell.exe`；Windows ARM64：`AgentBell-arm64.exe`。
- macOS Intel：`AgentBell-macos-x64.dmg` / `.zip`；Apple Silicon：`AgentBell-macos-arm64.dmg` / `.zip`。
- Linux x64 / arm64：`AgentBell-linux-<arch>.tar.gz`、`.AppImage`、`.deb`、`.rpm`。
- 全部资产由 `SHA256SUMS.txt` 校验；Windows、macOS 与 Linux 便携版都支持包内自动更新。

HTTP 服务仍只监听 `127.0.0.1`，会话记录只读，通知动作不执行外部命令，也不提供批准权限或自动继续。
