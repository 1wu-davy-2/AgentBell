## AgentBell 2.18.2

本次发布修复 Release 校验文件的缺项，功能与 2.18.1 相同。

### 修复

- Windows x64 与 arm64 打包任务此前都输出 `dist/SHA256SUMS.txt`，两个 artifact 合并发布时同名文件互相覆盖，导致 `SHA256SUMS.txt` 只包含 x64 的 `AgentBell.exe` 与版本化副本，缺少 arm64 的两个 exe。
- 现在 Windows 按架构输出 `SHA256SUMS-windows-<arch>.txt`，与 Linux / macOS 的命名方式一致；合并后的 `SHA256SUMS.txt` 覆盖全部 16 个可下载产物。

### 平台与下载

- Windows x64：`AgentBell.exe`；Windows ARM64：`AgentBell-arm64.exe`。
- macOS Intel：`AgentBell-macos-x64.dmg` / `.zip`；Apple Silicon：`AgentBell-macos-arm64.dmg` / `.zip`。
- Linux x64 / arm64：`AgentBell-linux-<arch>.tar.gz`、`.AppImage`、`.deb`、`.rpm`。
- 全部资产可用 `SHA256SUMS.txt` 校验，现在包含 Windows ARM64 条目。

macOS 14+ 版本仍为 ad-hoc 签名，首次打开需要右键「打开」；配置与数据位于 `~/Library/Application Support/AgentBell/`，更新方式为手动下载新包。
