## AgentBell 2.23.0

本次更新补齐外部 Agent 的数据接入面：通知可以携带模型、轮次、工具、文件与上下文摘要；外部 Agent 可上报 Token / 成本与活跃会话心跳；MCP 工具扩展到 5 个；并新增上下文压缩阶段与权限 / 提问等待的即时提醒数据支持。

### 新增

- 通知元信息：`/notify` 与 MCP `notify` 支持 `metadata`，扁平记录模型、轮次、工具调用数、文件数、上下文占用、压缩与授权等字段。卡片按固定顺序最多展示 4 个信息胶囊，存储与读取统一做键数、长度与字节上限清洗。
- 上下文压缩：`phase=compaction` 写入 `run_events`，时间线显示「上下文压缩」，卡片可显示压缩标记；不再需要把压缩伪装成 `note`。
- 权限 / 提问等待：`needs_input=true` 与 `wait_reason=permission|question` 现在可携带 `metadata.approval` 等上下文，沿用既有等待提醒、规则、去重与「待输入」筛选链路。
- 外部用量上报：新增 `POST /usage/report` 与 MCP `report_usage`，按 `report_id` 幂等写入持久化账本 `usage.sqlite3`（与 `agentbell.db` 同为配置文件同目录）；外部 Agent 的 Token 与成本会计入今日汇总、预算守卫和统计页「外部上报 N 条」。
- 外部会话上报：新增 `POST /sessions/report` 与 MCP `report_session`，以心跳方式把外部 Agent 的活跃会话显示在「进行中」。`status=ended`（也接受 `finished` / `stopped` / `canceled`）结束会话，默认 10 分钟无心跳自动过期；没有本地记录文件时，「查看详情」展示上报的详情文本。
- MCP 扩展：`tools/list` 现在返回 `notify`、`search_history`、`get_status`、`report_usage`、`report_session`；`get_status` 增加账本与会话注册表状态。

### API 示例

```bash
curl -X POST http://127.0.0.1:8765/usage/report \
  -H "X-Token: your-token" -H "Content-Type: application/json" \
  -d '{"model":"deepseek-chat","input_tokens":1200,"output_tokens":300,"cost_usd":0.002}'

curl -X POST http://127.0.0.1:8765/sessions/report \
  -H "X-Token: your-token" -H "Content-Type: application/json" \
  -d '{"session_id":"dsh-1","agent":"deepseek","title":"竞品分析","status":"running","turn":3}'
```

```json
{
  "title": "生成竞品分析报告",
  "status": "succeeded",
  "metadata": {
    "model": "deepseek-chat",
    "turn": 3,
    "tools": 8,
    "files": 5,
    "context_percent": 72
  }
}
```

### 说明

- 外部用量与会话都只写入本机 SQLite / 内存，不上传；`/usage/report` 需显式提供 `model`，未提供时返回 422。
- 外部会话默认 10 分钟 TTL；只展示心跳与上报字段，不读取外部 Agent 的本地文件。
- 所有新接口仍只绑定 `127.0.0.1`，与 `/notify`、`/mcp` 共用 token 鉴权；通知动作仍不提供批准权限、自动继续或命令执行。
- dsh 侧技能与插件本轮保持不变，仍只做每轮结束通知；需要用量与会话上报时可按上述接口自行接入。

### 平台与下载

- Windows x64：`AgentBell.exe`；Windows ARM64：`AgentBell-arm64.exe`。
- macOS Intel：`AgentBell-macos-x64.dmg` / `.zip`；Apple Silicon：`AgentBell-macos-arm64.dmg` / `.zip`。
- Linux x64 / arm64：`AgentBell-linux-<arch>.tar.gz`、`.AppImage`、`.deb`、`.rpm`。
- 全部资产由 `SHA256SUMS.txt` 校验；Windows、macOS 与 Linux 便携版都支持包内自动更新。

HTTP 服务仍只监听 `127.0.0.1`，会话记录只读，通知动作不执行外部命令，也不提供批准权限或自动继续。
