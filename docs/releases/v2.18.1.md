## AgentBell 2.18.1

本次发布修复 arm64 构建机上的测试失败，功能与 2.18.0 相同。2.18.0 标签因 CI 未通过而没有发布，2.18.1 补齐发布。

### 修复

- 更新器与资产选择测试不再依赖宿主机架构：此前在 Windows、Linux、macOS 的 arm64 runner 上，默认架构为 arm64，测试按 arm64 选包后与 x64 断言不符，导致三个 arm64 测试任务全部失败。现在用例显式传入 `machine`，x64 与 arm64 行为都被覆盖。
- 时间格式测试改为按本地时区换算旧时间，避免跨夏令时时预期小时数不一致。
- CI 测试失败时会把失败用例输出为 GitHub 注解，便于直接看到断言信息。

### 平台与下载

- Windows x64：`AgentBell.exe`；Windows ARM64：`AgentBell-arm64.exe`。
- macOS Intel：`AgentBell-macos-x64.dmg` / `.zip`；Apple Silicon：`AgentBell-macos-arm64.dmg` / `.zip`。
- Linux x64 / arm64：`AgentBell-linux-<arch>.tar.gz`、`.AppImage`、`.deb`、`.rpm`。
- 全部资产可用 `SHA256SUMS.txt` 校验。

macOS 14+ 版本仍为 ad-hoc 签名，首次打开需要右键「打开」；配置与数据位于 `~/Library/Application Support/AgentBell/`，更新方式为手动下载新包。
