## AgentBell 2.17.1

本次发布把 Linux 产物从单一 tar.gz 扩展为四种格式；Windows 版功能与配置保持兼容。v2.17.0 标签因 Linux 打包工具路径问题与 Windows 测试时序边界未通过 CI 而未发布，2.17.1 修复后发布，功能与 2.17.0 相同。

### CI 修复

- Linux 打包脚本在调用 `appimagetool` 前把工具与 runtime 路径解析为绝对路径，避免 `subprocess` 只按 PATH 查找而找不到仓库根目录下的工具。
- 等待扫描测试的会话年龄从 30 秒提高到 35 秒，避开文件时间戳取整导致的 `29 >= 30` 偶发失败。

### Linux 四种安装包

- x64 与 arm64 现在各提供 `tar.gz`、`AppImage`、`deb`、`rpm` 四种格式，全部由同一条 GitHub Actions 流水线构建。
- `tar.gz` 保持原样：解压即用，支持原地自动更新。
- `AppImage` 单文件运行：`chmod +x` 后直接启动，自动集成桌面图标。
- `deb` / `rpm` 可交给系统包管理器安装与卸载，主程序位于 `/opt/agentbell/AgentBell`，并提供 `/usr/bin/agentbell` 命令、桌面项与图标。

### 更新行为

- 便携 tar.gz 仍按当前架构下载 `AgentBell-linux-<arch>.tar.gz`，校验大小与 SHA-256 后替换并重启。
- AppImage 与 deb/rpm 安装不再尝试原地替换：AppImage 会提示下载新文件替换，系统包安装会提示使用 `apt` 或 `dnf` 升级。

### 发布流水线

- Linux 构建下载固定版本的 `appimagetool 1.9.1` 与 `type2-runtime 20251108`，两者都带 SHA-256 校验；AppImage 使用固定 runtime 打包。
- RPM 在构建时关闭 strip、debuginfo 与 build-id，避免破坏 PyInstaller 单文件可执行程序。
- 每个架构生成一份 `SHA256SUMS-linux-<arch>.txt`，发布任务再与 Windows 校验文件合并为 `SHA256SUMS.txt`。

### 下载与校验

- Windows：`AgentBell.exe`（自动更新资产）或带构建编号的副本，两者内容一致。
- Linux x64：`AgentBell-linux-x64.tar.gz`、`.AppImage`、`.deb`、`.rpm`。
- Linux arm64：`AgentBell-linux-arm64.tar.gz`、`.AppImage`、`.deb`、`.rpm`。
- 全部资产可用 `SHA256SUMS.txt` 校验。
