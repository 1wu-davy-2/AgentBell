## AgentBell 2.19.1

本次补丁修复 Linux 托盘菜单生命周期问题与 macOS 测试环境问题，功能与 2.19.0 相同。2.19.0 标签因 Linux arm64 与 macOS 测试未通过而没有发布。

### 修复

- Linux：托盘上下文菜单此前只作为局部变量传入 `QSystemTrayIcon`，Qt 不持有其所有权，Python 回收后打开「勿扰模式」等子菜单会触发 `QMenu already deleted`。现在托盘持有菜单的强引用，菜单在整个生命周期内保持可用。
- macOS 测试：窗口聚焦相关用例在 macOS 上仍保留 `_IS_MACOS=True`，导致 mock 的 Windows 路径被旁路。测试夹具现在在非 Windows 环境同时关闭 Linux 与 macOS 分支，让 Windows 路径按预期执行。

### 平台与下载

- Windows x64：`AgentBell.exe`；Windows ARM64：`AgentBell-arm64.exe`。
- macOS Intel：`AgentBell-macos-x64.dmg` / `.zip`；Apple Silicon：`AgentBell-macos-arm64.dmg` / `.zip`。
- Linux x64 / arm64：`AgentBell-linux-<arch>.tar.gz`、`.AppImage`、`.deb`、`.rpm`。
- 全部资产由 `SHA256SUMS.txt` 校验；Windows、macOS 与 Linux 便携版都支持包内自动更新。

HTTP 服务仍只监听 `127.0.0.1`，会话记录只读，通知动作不执行外部命令，也不提供批准权限或自动继续。
