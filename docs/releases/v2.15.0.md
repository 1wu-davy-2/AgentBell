## AgentBell 2.15.0

本次发布包含 2.14.0 与 2.15.0 的功能。

### 全屏提醒

- 新增「仅在主屏显示提醒卡片」：全屏遮挡仍逐屏铺满所有显示器（含任务栏），但只有主屏绘制卡片，副屏保留背景图与遮罩；点击任意屏幕仍会关闭全部提醒。配置项为 `overlay_area.card_on_primary_only`，默认关闭；可在「偏好设置 → 弹窗外观 → 全屏显示区域 → 多屏显示」中勾选。
- 同一条通知在多块屏幕间共享更新、脉冲与关闭状态，任意屏幕确认或点击遮罩都会一起关闭。

### 一键接入提醒

- 运行环境页新增「提醒接入」：可把等待确认、提问与每轮结束 Hook 写入 Claude Code、Gemini CLI、Grok 的用户配置；Codex 通过顶层 `notify` 支持每轮结束提醒。
- 写入前展示完整预览并按时间戳备份，只追加带标记的条目；已有 Hook、MCP 与密钥保持不变，可随时撤销，已有 Codex 自定义 `notify` 不会被覆盖。
- Hook 脚本只向 `127.0.0.1` 上报，不批准权限、不自动继续、不发送提示词。

### 设置与文档

- 偏好设置「全屏显示区域」新增多屏显示开关，保存后立即生效。
- README 与系统架构文档补充全屏多显示器、仅主屏卡片和提醒接入的说明。

### 下载与校验

下载稳定命名的 `AgentBell.exe`（供自动更新使用）或版本化的 `AgentBell-28.exe`，两者内容一致；可用 `SHA256SUMS.txt` 校验。
